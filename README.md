A one-line museum placard for an ordinary office stapler, recast as an ancient artifact: a forged-steel instrument of the Binding Rite, joining two sheets for eternity, donated by Accounts Payable. The program writes the placard (143 characters, inside the 180-character cap) to `entry.txt`.

## Run it

```sh
python3 main.py
```
